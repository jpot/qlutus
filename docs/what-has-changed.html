The main change: replace the old build chain

React 16 and Create React App have been replaced with React 19 and Vite. The application remains a static browser app, with the same Finnish clip catalog and existing styling.

01 / WHY

Upgrading react-scripts was not enough

react-scripts 5.0.1 was already its latest release. Create React App is deprecated; its dependency chain included many of the audit findings. Replacing it removes the legacy Webpack, Babel, Jest and Workbox stack rather than forcing incompatible transitive versions.

02 / RESULT

Current packages, reproducible installs

Every retained direct dependency matches the npm registry’s latest stable release at review time. Howler stays at 2.2.4 because it is already current. Test and build tools are now development dependencies. The lockfile is regenerated without peer-dependency bypasses or forced overrides.

Playback changes found during testing

Stop survives a queue edit

Before: adding or clearing a clip caused a React render that lost the current sound reference. Stop could no longer reach the playing announcement.

Now: a ref holds the active sound across renders. Stop works after queue edits, and stopped sounds cannot start the next clip through a late callback.

Play restarts one sequence

Before: repeatedly pressing Play could start overlapping sequences.

Now: Play stops and releases the previous sequence before starting the current queue. Finished clips, failed playback and component teardown release the active sound.

Queue semantics: edits affect the next announcement. A sequence already playing uses the queue captured when Play was pressed. Clearing the queue does not stop that sequence; use Stop. Clicking an individual queued clip still previews it independently.

Build and deployment changes to review
  • npm start retains port 3000; npm run build retains the build/ output directory.
  • index.html moves to the project root. JSX sources use .jsx. React mounts with createRoot and the modern JSX transform.
  • Relative asset paths support hosting under a subdirectory. Ogg clips remain separate files so Howler can detect their format.
  • CRA’s Browserslist and implicit ESLint build integration are removed. Vite uses its modern browser target; the checks here are behavior, browser and build tests.
  • npm test runs once; use npm run test:watch for watch mode. CRA’s eject command is removed.
  • Unused CRA service-worker registration code is removed; the existing unregister behavior remains. This upgrade does not add offline support.
Keeping dependencies current

Added a GitHub Actions workflow for clean installation, behavior tests, production build, Chromium tests and npm audit. Actions are pinned to the verified checkout 7.0.1 and setup-node 7.1.0 commit IDs. Dependabot checks npm packages and Actions weekly, grouping related React, Vite and Testing Library updates.

These configurations are committed locally. GitHub CI has not run, and alerts will not change until the updated branch reaches GitHub and is incorporated into the relevant branch.

Suggested manual review
  1. Add a greeting, an event name and a number. Play the announcement through your normal audio output.
  2. Add another clip while it plays, then press Stop. Confirm the announcement stops.
  3. Press Play twice. Confirm only one announcement sequence plays.
  4. Clear the queue, add a clip again, then try its individual preview. Review the existing independent-preview behavior.
